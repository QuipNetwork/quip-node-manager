    Network

    How peers reach your node. Once you forward two ports on your router, the defaults work for most home networks.

    Public address

    Advertising the detected address detecting…

    This sets the address peers are told to dial. Use it if your router forwards a different outside port, or if you have a DNS name. The port the node listens on is set separately, in Public API under Advanced.

    Other nodes will connect to this address as written, so check that they can reach this computer from outside your network.

    HTTPS

    This needs ports 80 and 443 and a DNS name that points at this computer. Certificates renew on their own.
    :20049 for local HTTP, or example.com, example.com:20049 for public TLS. Inside the container the port stays 20049. To change the public port, edit Public API under Advanced.
